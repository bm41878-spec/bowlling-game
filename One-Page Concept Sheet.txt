01. 기본 정보
   - 장르 / 서브장르 : 스포츠/ 캐주얼 스포츠
   - 타겟 플랫폼     : (PC Steam)
   - 시점 / 그래픽   : (3인칭)
   - 예상 가격       : (무료 또는 구독형, 1000원에 구매 가능)
   - 목표 출시일     : 2026-06
   - 개발 엔진       : Unity 6.x LTS

02. High Concept (1~2문장)
   "Switch Sports 볼링 같은 캐주얼 볼링 게임인데, 스페이스바 클릭 한 번만으로 조작이 완결되며, 색각 이상·소근육 조절 어려움·인지 부담 등 접근성 장벽을 시스템 레벨에서 제거한 게임."

03. 타겟 유저
   - 1차 타겟: (초등학생 저연령, 뇌병변장애인 혹은 발달 장애 학생)
   - 핵심 욕구: (성취감, 스트레스 해소, 집중력 강화)

04. 핵심 차별점 (USP) 
   - 1버튼/1클릭 완결 조작 (공 굴림 강도·방향 자동 보정 옵션)
   - 글자 크기 3단계, 모든 UI 텍스트 TTS 지원
   - 깜빡임·번쩍임 효과 완전 제거 모드 (광과민성 발작 대응)
   - 시간 제한 다소 완화(10초 -> 30초) / 실패 페널티 없음
   - 키 매핑 완전 커스텀

05. 레퍼런스 게임 3개
   - A Nintendo Switch Sports 자체 (3D 캐주얼 스포츠의 UI/UX 표준)
   - B Wii Sports Bowling (Shigeru Miyamoto 디렉팅) — 접근성과 캐주얼 스포츠 게임의 원형
   - C Microsoft Forza 시리즈의 접근성 옵션 (게임플레이가 아닌 접근성 시스템 자체를 참고)

06. Core Gameplay Loop (30초 ~ 3분 단위)
   1) 플레이어가 볼링공을 굴려 핀을 넘어트린다.
   2) 넘어트린 핀 만큼 점수를 얻는다.
   3) 점수를 얻어 성취감을 느낀다.
   → (1)로 복귀

07. 진행 구조
   - 플레이어의 목표 : 높은 점수 획득
   - 평균 1회 플레이 시간: 2~3분
   - 총 콘텐츠 분량 : 5분 

08. MVP
